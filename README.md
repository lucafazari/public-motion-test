# Motion test

A single page for trying touch and phone-motion input: swipes (one or two fingers), curved C / U strokes, tap + flick, tilt gate, phone turns, counter-turns, push / pull, tilts and grip + phone pull. Pick one from the menu, or Random; Retry repeats the same one. Each attempt says why it landed or failed.

Motion sensors need a phone and an https page (GitHub Pages works).
